# wnba (subproject of beating-the-opener)

Research conclusions + reproduce steps: README.md. Live experiment rules:
**live/PROTOCOL.md** - read it before touching anything under live/.

- When the user reports a bet fill in conversation ("got X over 3.5 at +128
  for $2"), follow live/PROTOCOL.md: append to live/bets.csv copying key
  fields from live/picks.csv, commit, push. Never invent fills.
- RESULTS.md and live/bankroll.json are auto-generated by src/settle_bets.py -
  never hand-edit.
- data/raw/bp/ is the committed line archive; the upstream API deletes old
  seasons, so never delete or gitignore it.
- Push directly to main (solo project).
