# What Phase 0 learned

**Recover the missing evidence before treating the next model as a valid test.**
The audit found useful archives and unresolved measurement problems. It did not
test a new model or establish a betting edge.

The props test may already be due. There are 6,711 coherent opening quotes in
the August archive. An exact-game ESPN count finds 6,324 played, non-push
outcomes and passes the 3,000 threshold on August 15. This is a count proxy;
the registration requires a wehoop rebuild and frozen model artifacts. Those
artifacts and an identifiable complete set of original August 1–3 opener-arm
predictions were not committed. Live base probabilities exist, but lack the
quote/recipe identifiers needed for this replay. Scoring today's rebuilt model
would not recover the original experiment.

The news log also needs more care than the brief assumed. Of 554 entries, only
343 name a game date. The audit matched an event for 221: 195 entries precede
tip and 26 do not. The remaining 333 need identity or validity-interval work.
No post-endpoint news outcomes are unlocked, so there is no honest human
minutes-accuracy baseline yet. Missing accuracy is not zero error.

The 242 availability snapshots are real. Narrative news is not archived: the
process keeps 413 seen IDs but no raw responses. The proposed change is to save
every successful raw news response, including unchanged firings, with source
and capture time. It needs approval because it changes a routine script.

Cricket does have intermediate prices: 1,163,261 observations. Its archive has
no closures after the prospective locks. Its claimed pre-toss clock also needs
independent event timestamps; it is currently inferred from later price moves.
The WNBA game arm includes playoffs and is not due at the regular-season end.

What changes now: explicit clock parsers, checksummed count evidence and a
review tool that preserves blocked windows. Live forecasts, records and
routines are unchanged. The next modelling step remains the structural minutes
and production distribution, followed by news only if calibration passes.

**2025 is reused development data.** Prior documented uses: WNBA fundamentals
v1, anchored v2, July audits/remediation, fp A/B/C, fp revisit, T1, both T2
iterations, oracle minutes, M, GG/GV2 game heads, v3 live-rule design and PR #2;
cricket P and Q; other-sport MLB K, NHL N/N2, NBA props, multi-sport screens,
soccer variants and NBA game diagnostics. The full experiment inventory is in
the audit. None of this establishes that structure beats the opener, that news
improves it further, or which market warrants a 2027 arm. Those remain untested.
