# Raw odds archive — aussportsbetting.com Big Bash League

`big_bash_league_wayback20231108.xlsx` — cumulative BBL results + odds file
(BBL01 2011/12 through BBL12 final, Feb 2023; 549 matches), retrieved from the
Wayback Machine snapshot 2023-11-08 of
`http://www.aussportsbetting.com/historical_data/big_bash_league.xlsx`
(live site is Cloudflare-blocked to non-browser clients).

Columns include Home/Away Odds **Open / Min / Max / Close** (compiled by
aussportsbetting from OddsPortal — multi-book averages), toss winner, batted
first, winner (H/A/D/V), DLS + Super Over flags, venue, round, scores.

Per the file's own terms: personal use only, do not redistribute the data —
this repo is private. Provenance: https://www.aussportsbetting.com/data/
(link when referring to the data set).

Top-up path for BBL13+ (2023/24 onward): download the current cumulative file
in a real browser from the same URL, drop it here alongside (do not replace
the wayback copy).
