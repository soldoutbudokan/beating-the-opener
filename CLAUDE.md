# beating-the-opener

Soccer 1X2 model that beats the opening line (see README.md for the research
result). A live FanDuel experiment is running: **live/PROTOCOL.md** defines the
picks → user-reported fills → settlement loop. If the user reports a bet they
placed ("got X at 2.60 for $2"), follow that protocol: log it in live/bets.csv
and push. RESULTS.md is auto-generated by src/settle_bets.py - don't edit by hand.
